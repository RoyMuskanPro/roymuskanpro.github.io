# Muskan Roy

Static personal portfolio landing page for `muskanroy.com`.

## Project Structure

- `index.html` - page markup and SEO metadata
- `css/styles.css` - all site styling
- `js/main.js` - theme toggle and background visualization
- `assets/images/` - profile image
- `assets/icons/` - favicon, Apple, Android, and Windows tile icons
- `site.webmanifest`, `browserconfig.xml`, `robots.txt`, `sitemap.xml` - SEO and device metadata

## GitHub Pages

This site is build-free. Publish it from the repository root using GitHub Pages.

1. Push this folder to a GitHub repository.
2. In GitHub, open Settings > Pages.
3. Set Source to `Deploy from a branch`.
4. Select the branch and `/ (root)`.
5. Keep `CNAME` if using `muskanroy.com`.
